# 字体来源与授权

| 文件 | 用途 | 来源 | 授权 |
| --- | --- | --- | --- |
| `SourceHanSansSC-Regular.otf` | 正文槽位（金句、清单项等） | [adobe-fonts/source-han-sans](https://github.com/adobe-fonts/source-han-sans) `release` 分支 `OTF/SimplifiedChinese/` | SIL Open Font License 1.1，可随仓库分发 |
| `SourceHanSansSC-Bold.otf` | 标题槽位（封面主标题等） | 同上 | 同上 |

- 版本：release 分支（2.004R 系），文件大小 Regular 16,529,832 B / Bold 16,963,428 B，可据此校验完整性。
- 通过 jsDelivr CDN 下载（`https://cdn.jsdelivr.net/gh/adobe-fonts/source-han-sans@release/OTF/SimplifiedChinese/...`），
  也可从 GitHub Releases 直接下载。
- 禁止依赖系统字体路径：imaging 服务只从本目录加载字体（计划书 6.3）。
