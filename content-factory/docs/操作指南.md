# 内容工厂 · 操作指南

面向使用者的日常操作手册：从启动服务到产出一条已发布内容 的完整流程。
工程实现细节（架构 / 迁移 / 测试 / Non-goals）见仓库根目录 `README.md`；
历史交付明细见 `docs/deliverables.md` 与 `docs/progress-*.md`。

## 总览：一条内容的生产线

```
内容栏目（关键词池，定义「采什么」）
   │
   ├── 小红书采样 / 公众号采样（RedFox 接口，按调用计费，confirm 后才发）
   ▼
素材库 hot_items ──► 爆款判定 ──► 灵感选题（一次性，按评分排）
   │                                   │
   └──► 「生成本周计划」周排期 ──► 本周栏目排期（系列内容）
                                       │
                            生成公众号 / 生成小红书（GLM，按 token 计费）
                                       ▼
                     文章页：复制 / 标题打分 / 违禁词体检 / 素材包
                                       ▼
                     手动发布到平台（站外操作）→ 回填互动数据
                                       ▼
                     效果分重算 → 选题排序 / 模板效果分 / 阈值校准（/stats）
```

## 1. 启动与配置

### 1.1 首次配置（`content-factory/.env`）

| 变量 | 用途 | 说明 |
| --- | --- | --- |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `MODEL_NAME` | 文案生成 | OpenAI 兼容协议（GLM / DeepSeek 均可），切换供应商不改代码 |
| `CF_REDFOX_API_KEY`（或 `REDFOX_API_KEY`） | 采样 + 违禁词体检 | 红狐数据（redfox.hk）密钥，按调用计费 |
| `NOTIFY_WEBHOOK` | 告警（可选） | 采集器连续失败 / 熔断时外发一次 |

参考 `.env.example`。**密钥只写在 `.env`（已 gitignore），绝不进代码 / 日志 / 提交。**
不配 RedFox Key 时采样与体检不可用；不配 LLM Key 时生成走 mock（仅能跑通结构，无真实文案）。

### 1.2 启动

```bash
cd content-factory
.venv/Scripts/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器访问 `http://127.0.0.1:8000/`。首次启动自动完成：建库（`data/app.db`）、
领域词表与提示词种子导入、内嵌采样 worker 启动，无需手动初始化。

模型也可以不配 `.env`：`/models` 页面运行时维护多套配置（详见 §7.4）。

### 1.3 页面地图

| 页面 | 地址 | 干什么 |
| --- | --- | --- |
| 工作台 | `/` | 本周栏目排期 + 灵感选题 + 两个采样入口按钮 |
| 内容栏目 | `/pillars` | 建栏目 / 周主题 / 定向采样 / 生成本周计划 |
| 素材采样 | `/viral` | 采样任务进度 / 手动喂样本 / 爆款样本表 / 熔断解除 |
| 文章 | `/articles/{id}` | 预览复制 / 打分 / 体检 / 素材包下载 / 数据回填 |
| 报表 | `/stats` | 成本 / 模板效果分 / 阈值校准（只读） |
| 模板管理 | `/prompts` | 提示词多版本管理与启停 |
| 模型配置 | `/models` | 运行时切换文案 / 图片模型 |

## 2. 从零跑通第一条内容（新手路径）

### 2.1 建栏目（`/pillars` → 新建栏目）

栏目 = 可持续更新的内容系列，五个要素：

- **栏目名称**：固定栏目名（如「本周5个值得装的AI工具」），每期复用；
- **固定角度 / 结构说明**：每期的写作框架，直接喂生成提示词；
- **关联领域**：可下拉官方类目或手填新领域（新领域连同关键词自动登记进词表）；
- **每周期数**：1 = 周更固定档；2-7 = 每周多期轮换；
- **采样关键词池**：逗号分隔，**这是采样的检索词来源**，也决定素材归队到哪个栏目。

辅助按钮：官方类目下可「获取推荐词」（调 RedFox 七日爆款，1 次计费）直接点选
热词；「找对标账号」（1 次计费）看该领域头部账号。

创建成功后**自动对该栏目词池发起一轮小红书采样**（默认开，`CF_PILLAR_AUTO_SAMPLE=false`
可关；公众号不自动采，计费纪律只留手动）。

### 2.2 采样（三个入口，效果一样，都是入队后台执行）

| 入口 | 位置 | 采样范围 |
| --- | --- | --- |
| 「小红书采样」/「公众号采样」按钮 | 工作台灵感选题区、`/viral` 页 | 全部启用栏目的关键词池合并 |
| 「采样一轮」/「公众号采样一轮」 | `/pillars` 每个栏目行 | 只采这一个栏目的词池（定向） |

- 检索词优先级：`.env` 显式配置（`CF_XHS_SAMPLE_KEYWORDS` / `CF_GZH_SAMPLE_KEYWORDS`）
  > 启用栏目词池 > 领域词表，上限 20 个词；
- **每关键词 1 次计费**：小红书每词拉 50 条近 7 天笔记；公众号每词拉 20 条近 30 天
  最热文章（优质库只覆盖**腰部以上公众号**）；
- 连点不重复计费：同一采集器已有排队/运行任务时直接复用；
- 进度看 `/viral`「采样任务」区或工作台采样引擎卡片（当前词 / 已抓取 / 已入库）；
  任务失败可在任务列表点「重试」（保留进度续跑剩余词），排队中的任务可取消。

采样入库后自动判定（纯规则，不调 LLM）：

| 平台 | 判定口径（初值，可 `.env` 热改） |
| --- | --- |
| 小红书 | 低粉爆款：粉丝 ≤ 5000 且 爆文率 =（点赞 + 2×收藏 + 3×评论）÷ 粉丝 ≥ 2.0（自动采样另有点赞 ≥ 500 预筛，人工喂的样本不预筛） |
| 公众号 | 阅读量 ≥ 10000 且 互动密度 =（点赞 + 在看 + 2×收藏 + 3×分享 + 3×评论）÷ 阅读 ≥ 0.08 |

达标样本进「爆款样本」表并**自动建选题**（撞题去重：标题相似度 ≥ 0.5 合并进旧题，
7 天窗口内）。

### 2.3 选题与排期

工作台有两类选题：

- **灵感选题**（一次性）：爆款判定建题 + 手动建题，按评分倒序，「保鲜」列显示
  72 小时过期时间。适合看到好素材立刻仿写一篇；
- **本周栏目排期**（系列）：`/pillars` 点「生成本周计划」从当周素材（小红书 /
  公众号 / GitHub 开源项目三源同池，按点赞倒序）派生选题。幂等：已排满的栏目
  自动跳过，重复点不重复建。

多期栏目推荐用**周主题**流程：栏目行「从本周素材生成主题建议」（LLM 归纳，需本周
命中素材 ≥ 3 条）→ 确认主题与子话题分期 → 「按主题重排」或「生成本周计划」，
各期围绕同一主题互补展开（主题会注入生成提示词）。

### 2.4 生成（选题行点「生成公众号」/「生成小红书」）

调当前生效的文案模型（`/models` 可切换），按平台模板生成。平台硬上限：

| 平台 | 标题 | 正文 | 其它 |
| --- | --- | --- | --- |
| 小红书 | ≤ 20 字 | ≤ 950 字（末尾标签行留余量） | 3-5 个标签 |
| 公众号 | ≤ 30 字 | ≤ 3000 字 | 摘要 ≤ 54 字（折叠位） |

超限不会入库：自动失败进重试，报错拼进提示让模型自纠（最多 3 轮）。生成成功后
小红书自动出 1080×1440 封面 + 金句图；公众号自动出 900×383 封面（PIL 本地渲染，
零计费）。

文章页还有三个再加工按钮：**重新生成**（同平台再来一次）、**改写为公众号长文** /
**改写为小红书笔记**（跨平台改写现有文章）。

### 2.5 文章页：发布前四件事（`/articles/{id}`）

1. **复制**：标题 / 正文 / 摘要一键复制；
2. **标题打分**：小红书六维（0-10 制）、公众号四维（0-100 制，赛道匹配 / 点击诱因 /
   结构合规 / 爆文潜质），给等级（S/A/B/C）+ 问题 + 建议 + 改写标题建议；
3. **违禁词体检**（RedFox 计费 1 次/篇，confirm 后才发）：平台词库分流（小红书 /
   微信公众号），命中词逐个可点「＋词」回填本地词表——回填后下次生成本地直接拦截，
   词表滚动扩充；
4. **下载素材包**：小红书 = `title.txt + content.txt + images/NN_kind.png`；
   公众号 = `title.txt + digest.txt + content.txt + images/01_cover.png`
   （digest 直接粘贴公众号后台摘要位）。

### 2.6 手动发布与回填

到小红书 / 公众号后台**手动发布**（系统不做任何自动发布——平台无官方 API，脚本
发布必触发风控）。发布后回文章页「发布回填」填真实数据：

- 小红书：点赞 / 收藏 / 评论；
- 公众号：阅读 / 在看 / 点赞 / 分享 / 收藏 / 评论。

保存后文章进 `published` 状态，**自动触发选题效果分重算**（同一选题多篇已发布文章
的互动加权求和），选题台排序随真实效果变化——这就是数据飞轮的入口。

## 3. 日常运营节奏

| 频率 | 做什么 |
| --- | --- |
| 每天 | 工作台看排期 → 生成当日内容 → 文章页四件事 → 手动发布 → 回填 |
| 每周一 | 栏目「生成本周计划」排期新一周；小红书周度拆解自动跑（周一 06:00，LLM 总结上周爆款样本的标题模式 / 情绪词 / 结构套路，结论回写样本表） |
| 每周四 | 阈值校准：`/stats` 校准视图看「当时判定 × 实际效果」交叉表，人工拍板改 `.env` 阈值，结论记录 `docs/p4-calibration.md` |
| 自动 | 每日数据库备份（保留 7 份）；素材库 90 天滚动清理 |

定时采样默认**关闭**（计费纪律，`.env` 加 `CF_XHS_SAMPLE_SCHEDULED=true` 开启，
间隔 `CF_XHS_SAMPLE_INTERVAL_HOURS` 默认 6 小时；公众号采样无定时，永远手动）。

## 4. 计费清单

### RedFox 积分（每次操作都有 confirm 确认）

| 操作 | 计费 |
| --- | --- |
| 小红书采样 | 每关键词 1 次 |
| 公众号采样 | 每关键词 1 次 |
| 手动喂公众号样本（贴 URL） | 每条 1 次；**未收录（502）不扣积分** |
| 违禁词体检 | 每篇 1 次 |
| 栏目推荐词 / 对标账号 | 各 1 次 |

### GLM tokens（按生成用量）

| 操作 | 计费 |
| --- | --- |
| 生成 / 重新生成 / 跨平台改写 | 每次按 token |
| 标题打分、周主题建议、周度拆解 | 每次按 token（远小于生成） |
| 模型配置页「测试」按钮 | 文案模型极小请求；**图片模型会真实出图计费 1 张** |

### 零计费

小红书手动喂样本（手填指标）、PIL 封面 / 金句图、素材包下载、效果分重算、
报表查询、GitHub 开源项目采集（公开接口限频 10 次/分钟）。

## 5. 数据回流与调优（`/stats`）

- **成本统计**：当月 tokens / 文章数 / cost_est，直接给「小红书平均单篇成本」。
  注意 cost_est 是估算口径——切模型后用 `CF_LLM_PRICE_INPUT / CF_LLM_PRICE_OUTPUT`
  按官方价修正（或在 `/models` 给每套配置填单价），否则不作账单依据；
- **模板效果分**：按提示词版本聚合已发布文章互动均值，published < 10 篇只展示
  不给启停建议；看哪个版本效果好 → `/prompts` 调整版本启停；
- **阈值校准**：爆款判定 × 实际发布效果交叉表 + 「按当前阈值现在会不会入选」复判。
  页面只读不给改阈值入口（防绕过校准会纪律），改值走 `.env`（热改即生效）。

## 6. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 喂公众号样本返回 502「优质库暂未收录」 | 优质库只收腰部以上公众号近 30 天文章，小众账号查不到；**未扣积分**。换头部/腰部账号的热门文章可正常入库；小众文章取数待广域库接口（推迟项） |
| 采样 / 喂样本请求很久没响应 | RedFox 接口延迟波动大（慢时 30 秒+/词，上限 180 秒），等终态即可；详情接口偶发响应体滴流挂起（罕见），重启服务清掉，无半成品风险 |
| 采样返回 409「已熔断」 | 该采集器连续失败 3 次自动熔断（防持续烧钱）。到 `/viral` 采集器状态表点「解除熔断」后重试任务 |
| 生成失败 | 文章页看 error 信息；超字数类失败会自动重试自纠（最多 3 轮），仍失败多为模型输出格式问题，点「重新生成」 |
| 生成结果是占位/mock 文案 | 未配置 LLM Key（或 `CF_LLM_MOCK=1`）：配 `.env` 的 `OPENAI_API_KEY` 或到 `/models` 添加配置并激活 |
| 想关掉建栏目自动采样 | `.env` 加 `CF_PILLAR_AUTO_SAMPLE=false` |
| 怎么重启服务 | 停掉 uvicorn 进程重新跑 §1.2 命令（数据库 / 素材 / 备份都在 `data/`，重启不丢） |

## 7. 进阶配置

### 7.1 采样关键词与上限

`.env`：`CF_XHS_SAMPLE_KEYWORDS` / `CF_GZH_SAMPLE_KEYWORDS`（逗号分隔，显式指定时
覆盖栏目词池）、`CF_XHS_SAMPLE_MAX_QUERIES` / `CF_GZH_SAMPLE_MAX_QUERIES`（默认 20）。

### 7.2 爆款判定阈值（热改即生效，结论记 `docs/p4-calibration.md`）

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `CF_VIRAL_FANS_MAX` | 5000 | 小红书低粉上限 |
| `CF_VIRAL_SCORE_MIN` | 2.0 | 小红书爆文率下限 |
| `CF_VIRAL_LIKES_MIN` | 500 | 自动采样点赞预筛 |
| `CF_GZH_READS_MIN` | 10000 | 公众号阅读量下限 |
| `CF_GZH_SCORE_MIN` | 0.08 | 公众号互动密度下限 |

### 7.3 手动喂样本（`/viral` → 人工喂样本）

- **小红书**：手填链接 + 粉丝 + 互动数（零计费），走同一打分建题管线；缺粉丝或
  数字非法会 422 提示；
- **公众号**：贴文章链接 + 领域 → 调 RedFox 详情接口自动抓全量指标（1 次计费，
  confirm 后才发）。URL 重复 409 不重复计费。

### 7.4 模型配置页（`/models`）

维护多套模型配置（名称 / base_url / api_key / 模型名 / 单价 / 思维链开关），
**文案与图片各设一个「当前使用」**，点一下即切换，下次生成即刻生效，无需重启。
api_key 明文只存本地数据库，页面 / API / 日志一律掩码；「测试」按钮图片模型会
真实出图计费 1 张（有确认提示）。AI 生图总闸 `CF_IMAGEGEN_ENABLED`（默认开）：
总闸关时配了图片模型也不出图，防误计费。

### 7.5 API 与 worker 分进程部署

长期 / 多人部署时 `.env` 设 `CF_WORKER_EMBEDDED=0`，分开跑 API 进程和
`python -m app.services.worker`（可多实例，原子领取不重复执行）。SQLite 单机
低并发够用；出现锁竞争常态化或要多人并发写时迁 PostgreSQL（见根 README）。

## 8. 安全与纪律（必读）

- **密钥只存 `.env`**（gitignore）与本地数据库，绝不进代码 / 日志 / 提交；
- 对外部平台**只用只读数据接口**：无关注 / 点赞 / 评论 / 私信 / 回关 / 自动发布，
  采样期间严禁任何账号互动操作（风控红线）；
- 服务只绑 `127.0.0.1`：Host/Origin 白名单不是用户认证，**暴露局域网 / 公网前必须
  先加认证**（否则任何人可触发付费采样与删数据）；
- 真实计费调用（RedFox / 真实 LLM 验收）全部人工触发且不进 CI；测试套件全程离线桩；
- 每日备份 `data/backups/`（保留 7 份），升级迁移自动先备份旧库再执行。
